
# Autodijelovi MEB

## 1. Project Description
Auto Dijelovi is a web application for browsing car parts.
The website includes a home page, product page, login page,
registration page, user profile, and vehicle compatibility check.

## 2. Entities
The planned database entities are:
- USERS – user information
- CATEGORIES – product categories
- PRODUCTS – car parts
- VEHICLE_CHECKS – vehicle compatibility information

## 3. Roles and Test Accounts
The website includes login and registration pages.
Test accounts and user roles have not been configured yet.

## 4. External API
The vehicle compatibility check page is currently a demonstration.
An external API has not been connected yet.

## 5. Running the Project Locally
1. Open the project in Visual Studio Code.
2. Open the frontend folder.
3. Start Live Server using index.html.
4. Open the local address provided by Live Server.
